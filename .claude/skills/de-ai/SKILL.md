# 去AI化写作

> **核心认知**：AI文本的问题不在词汇层面，而在认知层面。它不是"选错词"——它是用机器的方式在思考。所以去AI化 ≈ 用人的方式重新思考一遍，然后写出来。
>
> AI是集中规划型写作（先有骨架、再填内容），人类是局部推进型写作（一句带出下一句，边写边想）。这个差异是根本性的，单纯替换词汇骗不过任何人。

---

## 触发条件

"降低AI痕迹" / "去AI化" / "去AI味" / "这段太AI了" / "写得自然一点" / "帮我改改 一眼AI" / "太书面了 口语化一点" / "/de-ai"

用户可直接粘贴文字或指定文件。如果是文件，先 Read 再处理。

## Step 0：先读一遍，只问自己两个问题

动手改之前，读完原文，回答：

1. **这段话的"AI骨架"是什么？** — 找它的集中规划痕迹：是不是"现象→原因→影响→对策"？是不是"定义→分类→举例→总结"？找到那个藏在背后的模板结构，你就知道该破坏什么。

2. **如果是真人写这个内容，会怎么写？** — 真人不会先列大纲再填充。真人会从一个具体的事、一句吐槽、一个疑问开始，然后想到哪写到哪。

这两个问题的答案，决定了你接下来所有操作的方向。

## 改写强度分级

在执行具体操作前，先判断改写强度。用户可以直接指定：

| 强度 | 适用场景 | 做什么 |
|------|----------|--------|
| **L1 轻量** | 正式邮件、公文、学术论文 | 仅替换AI高频词汇，保留原有结构和书面感 |
| **L2 标准** | 公众号、知乎回答、工作汇报 | 词汇替换 + 句式破型 + 注入个人立场（默认） |
| **L3 深度** | 个人博客、随笔、重要发言 | 打散全文结构 + 重写开头结尾 + 加大量人味 |
| **L4 重写** | 需要完全看不出AI痕迹 | 只保留核心信息，从0开始用人的逻辑重写 |

默认使用 **L2**。用户说"大改"或"完全不像人"时上 L3/L4。用户说"轻一点"或"稍微改改"时用 L1。

---

## 核心操作库

以下每个操作都解决一个特定的"AI写作认知问题"。根据上一步选择的强度等级，组合使用。

---

### 操作 A：消灭模板结构（最重要）

AI文本的结构是"可见的"——读者能感觉到后面的骨架。人的结构是"不可见的"——你读的时候不知道下一段会是什么。

**破坏方法**（按力度递进）：

- **L1**：保留结构，但删掉"首先其次再次最后"这种路标词
- **L2**：把"综上/总之/总而言之"结尾改成戛然而止或反问
- **L2**：开头不要"随着...的发展"或"在...的背景下"——直接从中间开始。比如不说"近年来AI技术飞速发展，深刻改变着各行各业"，直接说"AI现在能写代码了，问题是，写得比一半程序员都好"
- **L3**：打乱原始段落的顺序。把中间某段移到开头，把原本的开头删掉
- **L3**：故意留一段"偏题"——写到一个相关但不在主线上观点，然后说"扯远了"
- **L4**：从0组织。先确定最想说的一个点，用它开头，其他内容作为补充散落在后面

**核心原则**：如果读者读完第一段就能猜到第二段要说什么，那就是AI结构。必须让它不可预测。

**具体替换表**：

| AI结构 | 替换为 |
|--------|--------|
| 开头 = 背景意义铺垫 | 具体问题 / 故事 / 争议 / 反问 |
| 中间 = 并列分论点 | 一个深入点 + 其他点一笔带过 |
| 结尾 = 总结展望 | 开放问题 / 戛然而止 / 一句评论 |
| 段间 = 逻辑连词 | 直接跳转（什么词都不用） |
| "首先...其次...最后" | 全部删除，或只剩一个 |

---

### 操作 B：词汇降维

AI词汇偏好"高维抽象"，人类词汇偏好"低维具体"。这不是简单的同义词替换——而是要降一个维度。

**B1. 抽象动词 → 具体动词**

| AI版 | 人类版 | 原因 |
|------|--------|------|
| 开展调查 | 查了一下 | "开展"是元操作词，人类不用 |
| 产生影响 | 改变了 / 坏了事 | "产生影响"不传达任何信息 |
| 发挥作用 | 有用 / 管用 | 同上 |
| 进行沟通 | 聊了 / 谈过 | "进行"永远可疑 |
| 予以回应 | 回了 / 答复了 | "予以"永远可疑 |
| 加以完善 | 改好 / 补上 | "加以"永远可疑 |
| 呈现增长态势 | 涨了 | "呈现...态势"是AI八股 |
| 实现突破 | 搞定了 / 拿下了 | "实现突破"太AI |
| 面临挑战 | 很难 / 不好办 | 降维 |

**B2. 修饰词瘦身**

AI喜欢在名词/动词前加修饰。删掉80%的修饰词，只保留有信息量的。

| 删掉（无信息） | 偶尔保留（有信息） |
|----------------|-------------------|
| 深刻改变 → 改变 | |
| 充分体现 → 体现 | |
| 有效提升 → 提升 | |
| 积极推动 → 推动 | |
| 高度重视 → 重视 | |
| 显著增强 → 增强 | |
| 全面的 / 系统的 / 深度的 | （几乎全部可删） |

**规则**：拿掉修饰词后句意不变 → 说明它是水词，删。拿掉后句意变了 → 保留。

**B3. 过渡词精简**

AI会高密度使用逻辑连接词，因为它在"编织"逻辑网络。人类更常用意合（语义自然连接），少用形合（连接词标记）。

| AI高频 | 人类替代 |
|--------|----------|
| 然而 / 但是 | 不过 / 可（或不写，靠语义转折） |
| 此外 / 另外 / 同时 | 还有 / 再说 / 顺便 |
| 因此 / 所以 | 所以（只保留一个，别每段都用） |
| 值得注意的是 | 删掉，或"其实" |
| 综上所述 | 删掉，或"说白了" |
| 毋庸置疑 | 删掉（说这话恰恰说明有人置疑） |
| 显而易见 | 删掉（真显而易见的不用说） |

**B4. 代词落地**

| AI版 | 人类版 |
|------|--------|
| 该公司 / 该机构 / 该产品 | 用名字 / 品牌名 / "这家公司" |
| 其发展 / 其影响 / 其意义 | 它的发展 / 删掉"其"，直接说 |
| 此举 / 该项 / 该事项 | 这个做法 / 这件事 |

---

### 操作 C：句式爆破

**C1. 破坏等长节奏**

AI倾向产出长度均匀的句子（每句25-35字，段段3-5句）。这是检测工具的核心指标之一（低burstiness）。

爆破方法：
- 每写完一个长句，接一个极短句（3-5字）。例："AI编代码的能力在过去两年翻了好几倍。是真的。"
- 一段可以只有一句话。
- 偶尔用句号制造断裂感。本来可以写成一个复句的，拆成两个单句，中间不加连词。
- 问句、感叹句、省略句混用。不是每句都以句号结尾。

**C2. 破坏工整排比**

AI爱排比，尤其是三连排比。看到一个三连排比就破坏一个。

| AI版 | 人类版 |
|------|--------|
| 我们要坚定信念，我们要勇往直前，我们要迎难而上 | 信念要有。方向对了就往前走。难肯定是难的，但也没别的路。 |
| 它改变了生产方式，重塑了商业模式，革新了社会结构 | 生产方式变了，商业模式跟着变。至于社会结构——这个影响可能被高估了。 |

**破坏技巧**：保留排比的第一项，后面两项换成不同句式或干脆不说了。

**C3. 加"元认知"标记**

人类写作时会"跳出"自己的思路审视一下。AI从不会这样。偶尔加入：

- "写到这儿我突然想到..."
- "其实说这么多，核心就一点：..."
- "扯远了，回来。"
- "这么说不准确，换个说法：..."
- "算了，这个话题太大，不展开了。"
- "你可能会问...这个后面再说。"

**C4. 故意留"毛刺"**

完美无瑕的文本就是AI文本。故意留一点不完美：
- 一个小众的、不太精准但生动的比喻
- 一个稍微口语化的表达
- 一句没有完全展开的想法
- 一个不太工整的对仗

---

### 操作 D：注入人味

**D1. 选一个立场**

AI永远在讲"一方面...另一方面..."。人类有立场、有偏见、有偏好。必须选边站。

- 如果原文分正反两面讲，砍掉一面，把另一面写深
- 用"我觉得"、"我反而觉得"、"说实话"、"讲真"
- 对某个观点表现出明显的情绪（赞同/质疑/不耐烦）

**D2. 用具体经历替代抽象结论**

这是去AI味最有效的手法之一：

| AI版（抽象结论） | 人类版（具体经历） |
|------------------|---------------------|
| 远程办公降低了团队沟通效率 | 我上周开了六个视频会，开到第四个的时候脑子已经是木的了，完全不知道前面讲了什么 |
| 过度使用社交媒体对心理健康有负面影响 | 刷了俩小时抖音之后那种空虚感，你懂吧 |
| 人工智能将替代部分重复性工作岗位 | 我一个做翻译的朋友，去年一半的活被机翻抢了 |

**规则**：每500字至少有一处"具体经历锚点"。

**D3. 语气词和口语标记**

按文体控制密度。正式文档（L1）少用，自媒体（L3）多用。

**语气词库**：
- 句首过渡：说白了 / 讲真 / 反正 / 说真的 / 你想想 / 是这样的 / 其实吧
- 句中插入：说实在的 / 老实说 / 有意思的是 / 烦的是 / 坑爹的是
- 句尾收束：吧 / 嘛 / 呗 / 就是了 / 就对了
- 情绪标记：哈哈 / 唉 / 啧 / 嗯 / 切

**标点的人化**（中文特有）：
- 减少句号密度：人类不会每句都完整收尾
- 适当用破折号（——）表示思维跳跃或补充
- 省略号不是"... "而是"……"（中文省略号）
- 偶尔不加标点，让句子自然断裂

**D4. 中文AI文的几个"绝杀"特征（必须消灭）**

以下特征是中文AI文本的"身份证"，看见必须处理：

1. **连续四字格**："真抓实干、锐意进取、开拓创新" → 三个四字格连用，99%是AI
2. **政论文体**："坚持以...为导向，深入贯彻落实..." → 除非真的在写公文，否则重写
3. **伪辩证**："既看到机遇，也正视挑战" → 看起来客观，其实是AI的认知偷懒
4. **结论先行+分点论证**：每段第一句就是结论，后面展开——这是教科书式AI结构
5. **安全牌收尾**："仍需进一步探索"、"还需持续关注" → 永远不下结论

## 工作流程

### Step 1：确认输入和强度

拿到文本。确认改写强度（默认L2）。如果用户没给强度，根据文体自动匹配：

| 文体 | 自动强度 |
|------|----------|
| 学术论文 | L1 |
| 工作邮件/公文 | L1 |
| 公众号/自媒体 | L3 |
| 知乎回答/博客 | L2-L3 |
| 工作汇报/周报 | L2 |
| 个人陈述/随笔 | L3 |
| 聊天/社交 | L4 |
| 简历/自我介绍 | L2 |

### Step 2：诊断（快速，30秒）

在心里标注：
- 模板结构痕迹 □有 □无
- AI高频词密度 □高 □中 □低
- 句式burstiness □均匀 □有变化
- 有无个人立场 □无 □有一点 □有

如果前三项都是最差值（有模板 + 高密度 + 均匀），直接用L3以上力度。

### Step 3：改写

按 Step 0 的两个问题和选定的强度等级，组合使用操作A~D。

**关键规则**：
- 不能只改词不改结构。词汇替换是必要条件，不是充分条件。
- 至少做一件结构层面的事（改开头/删结尾/打乱段落/插入元认知标记）。
- 改写后的文本读一遍：如果读起来没有"一个具体的人"的感觉，继续改。

### Step 4：自检

改写完成后，逐项确认：

```
□ 删掉了所有"进行/予以/加以"
□ 至少一处"具体经历锚点"或"元认知标记"
□ 段落长度有显著差异（不是每段3-5句）
□ 开头不是背景铺垫式
□ 结尾不是总结展望式
□ 有至少一处个人立场/判断
□ 三种以上句末标点（。！？……）
□ 不存在连续三个四字格
□ 不存在"一方面...另一方面..."
□ 大声读一遍——像人说话吗？
```

### Step 5：输出

直接给出改写结果。如果改动较大，简要标注做了什么（一句话）。

## 范例库

### 范例 1：学术风 → 人话风 (L3)

**Before:**
> 值得注意的是，在当今数字化时代，人工智能技术正在深刻地改变着各行各业的发展格局。从医疗健康到金融服务，从教育领域到制造业，AI的应用正在不断地拓展和深化。然而，技术的高速发展也在某种程度上带来了新的挑战和问题，需要我们予以高度重视。因此，如何在推动技术创新的同时有效应对潜在风险，成为了一个亟待解决的重要课题。

**After:**
> AI现在能看病、能写合同、能上课、能管工厂。说它没用那是假的。
>
> 但问题是——发展太快了。快到你还没想清楚怎么管它，它已经铺开了。
>
> 你说怎么办？先发展还是先监管？我觉得这不是二选一的问题。真正麻烦的是：管得太紧怕掐死创新，管得太松怕出事。
>
> 写到这儿我突然想到，其实大部分讨论这个问题的人，都没用过真正的AI产品。

**改了什么**：删掉模板开头，用具体场景重开；长短句交替（"说它没用那是假的"仅7字）；加立场（"我觉得"）；加元认知标记（"写到这儿我突然想到"）；结尾改成开放式观察而非"亟待解决的课题"。

### 范例 2：企业通知 → 真人沟通 (L2)

**Before:**
> 为了进一步提升团队协作效率，优化项目交付流程，经管理层研究决定，自下月起公司将启用新的项目管理工具。请各位同事予以积极配合，在规定时间内完成账户注册与数据迁移工作。如有任何疑问，请及时与IT部门取得联系。

**After:**
> 下个月我们要换项目管理工具了。具体哪天群里通知。
>
> 需要大家做的事就两件：注册账号、把旧数据迁过来。IT那边会出一个操作指南，照着做就行。搞不定直接找IT，别自己硬扛。
>
> 换工具的原因很简单——现在这个太慢了，查个任务状态要刷新三次。

**改了什么**：删"为了进一步"、"经研究决定"、"予以积极配合"；改成短句推进；加了原因解释（而且是用吐槽的方式）；做了信息分层（重要信息放前面，细节放后面）。

---

### 范例 3：AI味工作汇报 → 真人汇报 (L2)

**Before:**
> 本季度项目整体进展顺利，各项关键指标均达到预期目标。团队在产品功能迭代方面取得了显著成果，用户满意度较上季度提升了15%。在项目管理层面，我们进一步优化了敏捷开发流程，有效缩短了交付周期。展望下一季度，我们将继续深化产品能力建设，同时积极探索新的增长机会。

**After:**
> Q3 完成度大概80分吧。几个关键的：
>
> 功能迭代——该上的都上了，比计划晚了一周，主要是因为中间需求改了两次。
>
> 用户满意度涨了15%。说实话这个数字我也有点意外，看了一下主要是新版搜索立功了。
>
> 开发流程这块有改进——交付周期从两周缩到十天。不过还有空间，Code Review 环节经常卡。
>
> 下季度重点两件事：把搜索做到能当卖点的程度，然后看看能不能从企业客户那边撕开一个口子。

**改了什么**：打破"总结-成果-展望"模板；每段篇幅不同；加了自嘲（"说实话这个数字我也点意外"）；用口语化表达（"该上的都上了"、"撕开一个口子"）；结尾不是展望而是具体目标。

---

### 范例 4：AI味技术文章开头 → 人味开头 (L3)

**Before:**
> 随着大语言模型技术的不断发展，提示工程（Prompt Engineering）作为人与AI交互的关键环节，其重要性日益凸显。一个精心设计的提示词能够显著提升模型输出的质量和相关性。本文将从提示词设计的基本原则出发，结合实际案例，系统地介绍提升AI输出质量的实用技巧。

**After:**
> 我花了三个月，把 ChatGPT 的输出质量从"还行"提到了"能直接用"。核心秘密不是什么高级技巧——就是学会跟它说话。
>
> 这篇文章不讲理论。讲我实际踩过的坑、用过的招、以及十几个能直接抄的提示词模板。
>
> 先说最重要的一个原则，你记住这一个，就能超过90%的人：___

**改了什么**：从个人经历开头取代"随着...的发展"；直接告诉读者能获得什么；用"___"留悬念（人类写作技巧）；口语化（"踩过的坑"、"能直接抄的"）。

## 特殊说明

**英文文本去AI化**：以上原则同样适用，但英文AI有自己的特征词汇：
- 删除/替换：delve, navigate, leverage, pivotal, multifaceted, furthermore, moreover, consequently, notably, it is worth noting that, in conclusion, in today's world, it is important to note
- 英文人类更常用主动语态、缩略形式（it's, don't, can't）、短句、个人代词（I think, honestly, look）

**中英混排文本**：两种语言的AI特征都要处理，尤其注意中英混排时不要产生新的不自然感。

**用户说"不要改"的地方**：严格保留。如果因为不改某处导致通篇风格不统一，提示用户。

**处理长文本**：超过3000字的文本，分块处理。每块改完后检查语气一致性——不要前半部分活泼后半部分严肃。

**AI检测工具**：目前主流AI检测器（GPTZero, Originality.ai, 格子达等）主要基于perplexity（词语可预测性）和burstiness（句式变化度）。本Skill的所有操作都在提升这两个指标：替换AI高频词提升perplexity，打破等长句式提升burstiness。但请注意——没有任何改写方法能100%保证绕过检测。
